# XGN project instructions

## XGN project decisions

- Scoped refinements (2026-10-24): preserve the current logo, atmosphere, typography and all owner content. Cover year selection is a horizontal perspective carousel, never an arc: latest year first, selected year modestly larger, older years recede left with spacing and fading; support click, horizontal swipe and keyboard. Display 年度最爱 first without rewriting existing saved award order or other awards' relative order. - Visual final pass (2026-10-23): Preserve the approved composition during polish; redesign only when the user requests it. Keep the 4% outer grid on the hero, award nav and award list. Readable mobile year tabs over posters (top scrim). Buttons are dark glass with a poster-accent hover, never a solid colour fill. Uncollected cover years stay quiet but legible. The desktop music footer is a single full-width grid column; never add grid children that create a second column. For rendered UI changes, verify the affected views in real screenshots at 1440×900 and 390×844; documentation-only changes do not require browser checks.

- Cover (2026-10-23): root homepage opens with the existing XGN logo as the primary visual, one restrained entrance, horizontal year selection and one clear enter action. Cover XGN logo is `<Wordmark prism />`: sculpted brushed titanium with separated under-strokes and foreground bars for true intersection depth, directional multi-color prismatic rim reflections (`--logo-c1`..`--logo-c4` from `coverLogoPalette`), soft-light iridescent film drift, occasional specular sheen sweep, and hairline machined bevels. Never flat candy-colour fills or detached floating bars. The plain `<Wordmark />` in reader/editor headers stays unchanged. while year numerals and the cover primary accent/poster light follow `年度最爱` (`yearAccent` / `coverPrimaryEntry`). Use the approved cinematic ambient background with slow light motion; retain black, restrained typography and no slogans. Empty public years remain selectable in the horizontal row with a quiet not-collected state. Existing year/entry/query/preview links bypass the cover; returning home skips the full intro. Global audio defaults to playing on entry with a randomized starting track that avoids repeating the previous session's first track (`pickInitialTrackIndex`), unlocking seamlessly on first user gesture if browser autoplay is restricted; reduce motion with system preference. Do not add cover fields to the editor. Concept: design/cover-concept.png; reusable atmosphere: src/assets/cover-ambient.png.

- Public hosting (2026-10-23): use free Cloudflare Pages for the published static reader and retain the private Node 24/SQLite editor on D:/xgn. Build public mode into dist/public-site; never upload dist/client as a complete public site or upload data/backups/credentials. Export published snapshot read-only, copy only referenced media, include local fonts/music, stable year/entry routes and sharing metadata. Existing save-and-publish updates the same Pages project once connected. Show local-save/upload/live/failure separately and support retry. Preserve all owner content, passwords, drafts and sessions. Do not add a remote CMS or paid service.
- Live Pages project: xgn-e2d48135eb, https://xgn-e2d48135eb.pages.dev (first deployed 2026-10-23). Reuse data/publishing.json and this project; never create a new project for routine updates. Active Windows launcher/editor uses 127.0.0.1:4174; direct server.mjs still defaults to 4173. Use the configured launcher port and identify any existing process before managing it.

- Final polish (2026-10-23): the active project is D:/xgn. Self-host one Noto Serif SC family (400/600/900), one Noto Sans SC family (400/600), and Bodoni Moda lining/tabular numerals through the numeric font alias; do not depend on locally installed Source Han/Songti/SimSun fonts. Fontsource Unicode WOFF2 shards must cover future owner-authored titles too. Keep the hero copy low, sharing next to reading, dark scrollable award navigation with edge fades/arrows, 60px compact award rows without repeated 年度, and subdued empty states. Reserve an independent desktop music footer; on mobile use only a 44px play/pause circle. Preserve owner data and the simple editor.

- Typography and content: preserve the cinematic black composition, custom XGN wordmark and short functional labels. 年度最爱 has the strongest emphasis; year numerals, work titles, scores and selected awards use their poster-derived palette, with neutral surrounding text. No fixed gold favorite theme, slogans, decorative English headings, giant duplicate XGN/year titles, repeated intros, flashing or showy neon. Preserve owner-authored citations and poster choices.

- Follow-up (2026-10-22): 年度遗珠 is an unranked collection with direct add/switch/remove/undo in the editor and a poster gallery in the reader. Other awards retain the cinematic hero. Support zero/one/many entries and blank/zero scores. Music is global interface music: an ordered loop of supplied files, persisted across years, awards, editor and preview. A compact player offers play/pause, next and volume. No per-year music or library-style management. Do not ship synthetic test music. Music changes publish independently of annual awards. Audio is private until published and included in backups. The user supplied eight actual tracks, packaged in content/music and installed once without overriding later choices.

- Editor simplification (2026-10-22): the everyday form must contain only poster upload, name, score and award citation. Choose year and award, then fill directly. Put focal point, source/scope, multiple entries, backup, annual intro and other infrequent controls behind settings. Prefer one prominent save-and-publish action. All twelve discussed award names are included by default. Do not grow the main form back into a CMS.

- This is a complete single-owner annual awards project: React/Vite frontend and Node 24 + SQLite backend, not a browser-storage-only demo.
- Organize by year then personal awards. No film/game/book genre taxonomy. A whole work or a complete narrative segment can enter. Multiple winners and nominees are supported.
- Use the selected cinematic black XGN composition (exec-c41f98ae-d5d8-4108-87cb-6a17c6032532.png). Posters must be replaceable uploads with automatic masks, palette extraction, focal point controls and shared animation, never one-off generated pages.
