# XGN · 我的文娱年度评选

这是一个可以独立维护的个人年度评选网站。私人编辑台和数据库留在本机，已发布内容导出为独立静态网页，使用免费的 Cloudflare Pages 分享。作品、海报、配乐和历史年份按数据库保存，导出不会重置内容。

此仓库保存可运行的项目源码，排除原站数据库、密码、会话、草稿、Cloudflare 凭据及个人音乐。首次运行将创建独立本地数据；如需迁移自己的内容，请在原编辑台导出完整备份后导入新实例。在线演示链接继续使用原站，克隆仓库不会获得原站发布权限。

## 产品方向

- 首页为独立封面：XGN 字标先入场，年份横排、点击进入年度；背景有缓慢光影动效。空年份选择后显示尚未收录，不进入空白奖项。返回封面不重复完整片头，作品和年份直达链接仍绕过封面。音乐保持全站连续，播放由用户明确点击；系统减少动态效果时关闭封面动画。设计与素材提示词见 `design/cover-art.md`。

- 每年年底集中编选，可补录往年。按「年份 → 奖项」组织，不按电影、游戏、小说等媒介分类。
- 完整作品、一季、章节、角色线或一段完整剧情都能参评；在名字里写清作品和片段即可。额外的所属作品、范围信息收在补充设置。
- 默认包含全部 12 个奖项：最佳剧情、最上瘾、最失望、出乎意料、最爱、最难释怀、最佳角色、最佳关系、最佳瞬间、最佳氛围、声音记忆、遗珠。可以在设置中改名、增删和排序。
- 一个奖项可放多个获奖条目，也可标记提名；多个获奖条目即为并列。可以复用已有海报和文字，不需要重复上传，同一次复用之后的文字可独立编辑。
- 「年度遗珠」直接支持多部：在表单上方添加、切换作品；移除后可原位撤销。前台按添加顺序展示海报卡，不按分数排名；单部用较大卡片，无海报有文字卡兜底。每部独立查看评分、颁奖词和剧透提醒，也可分享单部或整份遗珠。
- 日常只填海报、名字、评分和颁奖词。评分为 0–10 分，可以留空；颁奖词支持分段，并自动生成首页摘要。可选「颁奖词含剧透」，摘要会替换为不透露剧情的提醒。
- 黑色为主，作品海报成为大画面。上传后自动适配尺寸、提取点缀色，并通过统一渐变遮罩融入黑底。图片不由 AI 重绘，不需要逐张设计。图片位置、完整海报模式和手选颜色收在「图片与补充设置」。
- XGN 使用专属切角字标；12 个奖项通过字距、细线、断线和刻度区分，「年度最爱」保留更突出的字形与双线。字标反光、当前年份、奖项标题和评分跟随海报取色，奖项索引也能使用各自获奖作品的颜色。切换时短暂显影，静止阅读时不持续闪动。
- 字体随网站加载：中文宋体统一为 Noto Serif SC（400／600／900），小字统一 Noto Sans SC，数字统一 Bodoni Moda 的等高、等宽数字。Fontsource 字符分片按实际内容请求，未来新增的作品名也能覆盖；不依赖访客电脑安装的思源宋体。字体许可证随静态资源提供。
- 首屏文字靠近底部奖项导航，分享紧邻阅读按钮。奖项导航有深色底带、两端渐隐和左右按钮；全部奖项采用约 60px 行高、省略重复的「年度」前缀，空项调暗。
- 动效集中在年份/奖项切换、画面显现、文字进入和按钮反馈；系统开启「减少动态效果」时自动收敛。
- 背景音乐全站共用，在「设置 → 背景音乐」添加或移除音频。桌面播放器占用独立底栏，支持下一首、暂停、音量和静音；手机只显示一个 44px 播放／暂停圆钮。切年份、奖项、编辑台和预览都不中断；首次点击播放后持续播放。没有音乐时隐藏播放器。
- 访客不需要登录；只有站主能编辑。每个年份、作品条目均可通过链接定位分享。

## 现在怎样使用

启动入口的本地阅读地址：`http://127.0.0.1:4174/`  
编辑台：`http://127.0.0.1:4174/edit`

首次进入编辑台，请自己设置至少 8 位的密码。随后：

1. 新建一个年份，或选择一个旧年份补录。
2. 选一个奖项，不用额外点「添加作品」。没有填写的奖项可以先空着。
3. 上传海报，填名字、评分和颁奖词。
4. 点「保存并发布」，保存这个年份的公开版本；连接 Cloudflare 后会自动更新分享网站。
5. 暂时不想公开时，点旁边的「保存草稿」；「看看效果」会打开私人预览。
6. 备份、年度开场白、奖项管理等功能都收在右上角设置里。
7. 在设置中管理背景音乐，点「保存音乐」立即更新全站音乐，不会公开其他未发布的评选。源码仓库不附带个人配乐，请上传自己的音频。

示例年度可以直接编辑；第一次保存发布后会自动成为你的正式评选。不需要的公开示例可以在「设置 → 管理这个年份」先撤下，再移除草稿。

发布状态会区分本机保存、正在上传、上线成功和失败。只有显示「分享网站已更新」才代表网上版本已更新；失败时本机内容仍保留，可以重试。「保存草稿」不会替换公开页面。在站内返回或离开编辑台时会先保存草稿；刷新或关闭浏览器时，未保存内容仍有浏览器提醒。私人预览带有「仅你可见」标识，未登录无法读取。

## 启动与开发

需要 **Node.js 24 或更新版本**，使用内置 SQLite，无需单独安装数据库。

```powershell
npm ci
npm run build
npm start
```

Windows 可双击项目里的 `启动XGN.cmd`。启动入口默认使用 4174 端口，可用 `XGN_LAUNCH_PORT` 覆盖；直接运行 `server.mjs` 默认仍为 4173。服务已经运行时会直接打开网页；尚未运行时会先启动，等待就绪后再打开。只有缺少构建文件时才会安装必要依赖并构建。由脚本新启动服务时，请保持服务窗口打开；启动失败会保留窗口显示原因。批处理使用 Windows CRLF 行尾和纯 ASCII 命令，避免编码导致双击闪退。

开发模式：

```powershell
npm run dev -- --port 4173 --strictPort
```

开发服务器与正式服务器共用同一套 API。`npm run preview` 也会运行完整 Node 服务，不是仅支持静态页面的 Vite preview。

## 数据与备份

- 默认保存在 `data/xgn.sqlite`。文字、草稿、公开版本、上传海报、音频以及登录信息都由 SQLite 管理，不依赖浏览器缓存。浏览器只额外记住访客的音量偏好。
- 完整备份 JSON 包含已保存的草稿、公开版本、上传海报与音频，不包含密码哈希及会话。旧版无配乐的备份仍可恢复。
- 从备份恢复会替换内容，并保留一次恢复前的状态；「备份 → 撤销上次恢复」可以撤回。
- 草稿删除、移除作品等操作在保存前可用「设置 → 撤销未保存修改」恢复；长期恢复依靠完整备份。
- 海报上传支持 JPG、PNG、WebP、GIF；浏览器将最长边控制在 2560 像素内并转为 WebP。GIF 使用首帧作静态海报。原始上传文件上限 30 MB，服务端单张处理后图片上限 12 MB，备份恢复上限 200 MB。
- 音乐支持 MP3、FLAC、M4A、WAV、OGG，每首上限 30 MB。按实际文件头识别格式，支持分段读取。备份只包含草稿或公开内容仍在使用的媒体，排除废弃上传。原项目的 8 首个人配乐不随源码分发。
- 未公开条目上传的图片不能通过匿名请求读取。取消发布后，公开页面会移除该年度；访客此前自行保存的内容自然不会被远程删除。
- 可使用 `XGN_DATA_DIR` 指定独立数据目录。测试均使用工作目录下的隔离数据库。

忘记编辑密码时，在服务器本机重设（会退出所有已有编辑会话）：

```powershell
$env:XGN_NEW_PASSWORD='在这里设置你自己的新密码'
node scripts/reset-password.mjs
Remove-Item Env:XGN_NEW_PASSWORD
```

不要把包含个人备份或正式数据库的目录提交到公共仓库。

## 分享与正式部署

默认使用 **Cloudflare Pages 免费静态托管 + 本机私人编辑台**。不需要购买域名或服务器。网站上线后，关闭本机不会影响访客访问；编辑仍需在本机进行。

固定分享地址：[XGN](https://xgn-e2d48135eb.pages.dev)。2026-10-23 已完成首次部署。

首次双击 `连接分享网站.cmd`（或运行 `npm run connect`）：在浏览器完成 Cloudflare 登录与 Pages 授权，脚本创建并记住一个免费项目，然后发布已有公开内容。再次运行会复用相同项目。账号登录和授权需要本人确认，不要把 Cloudflare 密码或令牌贴进评语或代码。

后续继续双击 `启动XGN.cmd` 进入编辑台，选年份与奖项，上传海报、填名字、评分和颁奖词，点「保存并发布」。分享地址保持不变。上传失败时点击「重试发布」，或双击 `更新分享网站.cmd`。发布期间请保持本地服务运行，等状态显示成功再关闭。

`npm run export:public` 只生成 `dist/public-site/`，不会上传。这个目录含公开文字、引用中的海报、音乐、字体和网页；**不含数据库、草稿、密码、会话或弃用媒体**。不要把整个项目、`data/`、备份或 `dist/client/` 直接上传当公开网站。年份链接为 `/year/2025/`，作品链接为 `/year/2025/entry/作品编号/`，附带标题和海报元数据；聊天软件是否显示预览由其自身决定。

发布设置和状态在本机 `data/publishing.json`、`data/publishing-status.json`，失败日志在 `data/publishing.log`。Cloudflare 登录凭据由 Wrangler 自行保存在本机用户配置中，不写入公开目录。换电脑时应保留完整内容备份和发布设置，在新电脑重新登录 Cloudflare。

当前公开包遵守免费限制：最多 20,000 个文件、单文件不超过 25 MiB。未来上传过大的音乐会阻止上传并保留旧线上版本，需要压缩后重传。免费境外节点在中国大陆的可达性和速度因网络而异，不保证全地区稳定。

如果将来需要远程在线编辑，也保留以下完整 Node 服务部署方式：

完整后台需要能运行 Node 24 并持久保存数据的环境。项目提供 Dockerfile 和 Compose 配置，可部署在自己的服务器。步骤：

1. 将 `.env.example` 复制为 `.env`，设置自己的初始管理员密码。
2. 运行 `docker compose up -d --build`。
3. 为 `127.0.0.1:4173` 配置 HTTPS 反向代理，代理需保留原始 Host 请求头。
4. HTTPS 环境中设置 `XGN_SECURE_COOKIE=1` 并重启容器。
5. 通过网页导入本地完整备份。密码仍使用线上独立设置的密码。

Compose 默认只将服务端口绑定到服务器本机，数据使用 `xgn_data` 持久卷。服务器和域名需要另行准备；该完整后台部署方式需要自行配置。首次远程部署必须设置 `XGN_ADMIN_PASSWORD`；已有管理员时该变量不会覆盖现有密码。

如果需要 Nginx，反向代理配置可参考：

```nginx
location / {
    proxy_pass http://127.0.0.1:4173;
    proxy_set_header Host $http_host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    client_max_body_size 205m;
}
```

该段需放在你已配置 HTTPS 的站点中。上传/恢复请求超时应按实际备份大小调整。项目自带的 Product Design 静态 Sites Worker 已保留，但它不包含 Node/SQLite 后端；不能只上传静态 `dist/client` 就声称编辑与存储功能已经上线。

```text

server/api.mjs        权限、媒体读写、草稿/发布、备份恢复 API

```
